# 2.161.0

First packaged release.

- **Install from a signed package.** A notarized `.pkg` installer sets up
  Stenographer without needing a source checkout. An optional component
  installs the `claude-account` shell integration (off by default).
- **Automatic updates.** Stenographer now checks for updates in the
  background and offers them from a new **Check for Updates…** menu item.
- **Smoother updates.** After installing an update, Stenographer finishes
  its own setup automatically — no manual steps required.
- **The command-line tool is now `snog`.** It replaces `stenographer`;
  setup moves your status line over to it automatically.
- **Burn rate in Account Quotas.** Each account shows how fast it is using
  its quota, accounts can be reordered, and a seal marks each quota's state.
- **Reliable account switching.** Switching Claude accounts no longer loops
  on password prompts, installs an expired login, or loses a renewed token.

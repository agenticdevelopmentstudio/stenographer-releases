# 1.1.0

- **Simpler version numbers.** Stenographer's versions now read
  `major.minor.patch` — this release is 1.1.0 — in the app, the installer,
  update notices, `steno --version` and `steno health`, which now report the
  same version.
- **Clean upgrades over earlier copies.** The installer now removes earlier
  Stenographer apps from Applications before installing, including copies
  built before 1.0, so you are left with one Stenographer instead of two, or
  one installed inside a folder. It also stops the background service and
  menu bar app those copies started.
- **One password prompt during setup.** Setup steps that need administrator
  rights now share one prompt instead of asking for your password again for
  each step.
- **The status line turns on when none was set.** Turning on the Claude Code
  status line no longer fails with "XPCRefusal error 1" when Claude Code had
  no status line configured. It now fills the empty setting, and when the
  background service turns a request down, the message says why.
- **Your window settings carry over.** Window positions and other settings
  from Stenographer versions before 1.0 are brought over on upgrade, even when
  the new version has already saved some settings of its own. Settings you
  have already changed are never overwritten.

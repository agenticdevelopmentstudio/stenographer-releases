# 1.2.0

Stenographer is in beta. These are the changes since 1.1.0.

- **Windows reopen after an update.** Windows that were open when an update
  restarted the app should now reopen, whichever version saved them. Before,
  an update could leave every window closed. Automated tests cover this, but it
  has not yet been checked through a real update.
- **Install Updates Automatically can be turned off.** Updates install on
  their own by default. The app menu now has an **Install Updates
  Automatically** item next to **Check for Updates…**; uncheck it to choose
  when updates install.
- **The Fable gauge shows again.** The Claude Fable usage gauge had gone
  missing from the quota row and the widget. It is drawn again, and it no
  longer switches between two different estimates when a reading fails.
- **Saved Claude logins stay on this Mac.** Logins are now kept only in this
  Mac's login keychain, because a login shared through iCloud Keychain could
  sign your other Macs out of Claude Code. Long-lived setup tokens are still
  shared through iCloud. A login you saved only on another Mac needs a
  `/login` once on this one. The Storage setting is gone; **Stored in** shows
  where each credential is.
- **Switching accounts.** The quotas window is covered with "Switching to
  <name>…" until the switch finishes, instead of showing the old account
  first for a while.
- **The status line can share Claude Code's setting.** Claude Code allows only
  one status line command. Stenographer now installs a small shared launcher
  at `~/.claude/claudehelpers/statusline` that can run its status line
  alongside another tool's. If the status line fails, the reason is shown in
  **Manage Tools** and by `steno health`.
- **A faster status line.** The status line no longer waits for usage data to
  be recorded before it appears.
